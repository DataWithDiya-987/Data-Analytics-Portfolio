## Jobs and Automation Insights 2030 | Excel Dashboard

## Project Overview

This project focuses on analyzing the impact of Artificial Intelligence and automation on
future employment trends using Microsoft Excel. It explores job replacement risks, 
industry-wise hiring trends, projected job growth, and automation levels through an interactive dashboard.

## Tools Used
-Microsoft Excel
-Pivot Tables and Pivot Charts
-Data Cleaning and Transformation
-Excel Slicers and Interactive Filters
-KPI Cards
-Data Visualization
-Key Insights
-Analyzed AI replacement risks across different job roles.
-Explored hiring trends across multiple industries.
-Evaluated projected job growth by industry for 2030.
-Analyzed automation levels across different industries.
-Compared performance scores across automation levels.
-Developed an interactive dashboard using slicers for dynamic data analysis.
