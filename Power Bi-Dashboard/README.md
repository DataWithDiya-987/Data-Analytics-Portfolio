## Oil Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing oil sales data using Microsoft Power BI.
It provides insights into sales performance, revenue trends, product brands, manufacturers,
and city-wise sales distribution through interactive dashboards and visualizations.

## Tools Used
-Microsoft Power BI
-Power Query
-DAX (Data Analysis Expressions)
-Data Cleaning and Transformation
-Data Visualization
-Interactive Slicers and Filters
-KPI Analysis
-Key Insights
-Analyzed overall oil sales performance and revenue trends.
-Evaluated sales distribution across different manufacturers and brands.
-Identified city-wise sales performance.
-Monitored key performance indicators (KPIs).
-Created interactive dashboards to support data-driven business decisions.
