## Tech Hiring & Layoff Trends Dashboard

## Project Overview
This project focuses on analyzing technology industry hiring and layoff trends using Tableau.
It provides insights into workforce changes, company hiring patterns, and layoff trends
through interactive dashboards and visualizations.

## Tools Used
*Tableau
*Data Cleaning
*Data Visualization
*Interactive Filters
*Charts and KPI Analysis

## Key Insights
*Analyzed technology hiring and layoff trends.
*Identified patterns in workforce reductions.
*Explored hiring trends across companies and industries.
*Created interactive visualizations to support data-driven insights.
